# Mac 本地按需运行

本地入口使用可见的 Chrome 和独立、持久的浏览器资料目录。第一次在弹出的窗口扫码登录，以后复用同一份资料，不需要导出 Cookie 或填 GitHub Secrets。电脑只需在运行期间唤醒并联网，运行结束即可关闭；本方案没有自动定时任务，也不能在 Mac 关机时由 iPhone 独立执行。

首次下载后先运行仓库根目录里的 `安装Mac版.command`，再双击 `本地续火花.command`。需要 Python 3.11+；依赖安装到本项目的 `.venv`。

首次使用按菜单操作：

1. 选 `1`，在浏览器完成登录，看到私信列表后回终端按回车。
2. 选 `2`，一行一个输入要发送的昵称，再输入消息文字并保存。
3. 选 `3`，只检查好友定位，不发送。
4. 选 `4`，核对名单及文字，输入「发送」才执行。

日常使用可以双击仓库根目录里的 `快捷续火花.command`，核对弹窗中的好友和消息，点击「发送」即可。程序自动使用已保存的配置和登录资料，完成后退出，不用输入菜单编号或再输入 `0`。点击「取消」不会启动发送。运行 `创建桌面入口.command` 可创建桌面快捷方式。

修改好友或消息、更新登录时使用原来的 `本地续火花.command`。快捷入口与旧菜单不能同时占用浏览器；若旧菜单还在运行，先输入 `0` 退出。终端是否自动关闭窗口取决于 Terminal 设置；程序结束后可以直接关掉窗口。

登录、配置、发送历史及失败截图保存在本机的 `local-mac/`，已加入 Git 忽略。已确认成功或结果不确定的同一条消息，当天不会自动重发；失败后应在抖音核实，必要时自行补发。

本地版复用上游的好友定位和发送代码，已在维护者的 Mac 上验证运行。云端发送失败的根因尚未确定，其他账号和机器仍需实际验证；如出现失败，应按本地截图继续诊断。本地入口不会停用 GitHub 工作流、外部定时器或旧程序的定时任务；若之前启用了它们，请分别关闭，避免多个入口同时运行。
